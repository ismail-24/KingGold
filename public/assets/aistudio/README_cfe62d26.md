# King Gold — نموذج Flutter مبدئي

نموذج أولي قابل للتشغيل الفعلي على الموبايل، ببيانات ستاتيك (Mock)، لتجربة فكرة
"سوق ذهب موثّق" قبل ربط أي API حقيقي.

## التشغيل

```bash
flutter pub get
flutter run
```

لو حابب تجربه على جهازك مباشرة: وصّل الموبايل بالكابل وفعّل USB debugging
(أندرويد) ثم `flutter run`، أو افتح محاكي iOS/Android وشغّل نفس الأمر.

## فكرة الهوية البصرية (مش قالب فينتك جاهز)

- **الألوان**: دهب نحاسي عتيق (Brass) بدل الدهب اللامع، وأسود دافئ بدل
  الأسود الخام، على خلفية "ورق دفتر" كريمي — إحالة لدفتر حسابات الصائغ.
- **الخطوط**: عنوان بخط Amiri (عربي تقليدي بيحمل طابع الدمغة)، ومتن بخط
  Cairo (حديث للقراءة اليومية). التناقض ده مقصود.
- **شارة الثقة**: بدل أيقونة ✓ خضرا عادية، فيه `SealBadge` مرسوم بالكود —
  ختم دائري بأسنان زي دمغة الصائغ الحقيقية، مستخدم في كل مكان نقول فيه "موثّق".
- **كارت الفاتورة (`LedgerCard`)**: حواف حادة وخط منقط بين البنود، زي إيصال
  محل الذهب الحقيقي، بدل كروت SaaS الموحّدة.
- **اللحظة الحيّة الوحيدة**: شريط السعر اللحظي (`LivePriceTicker`) بيهتز رقمياً
  كل كام ثانية بحركة بسيطة، عشان يحس المستخدم إن السعر فعلاً لحظي، من غير
  ما نملى الشاشة بحركات في كل مكان.

## هيكلة المشروع

```
lib/
  theme/        نظام الألوان والخطوط (Design tokens)
  models/       الموديلات: Shop, Product, GoldOrder...
  data/         بيانات Mock + AppStore (حالة السلة والطلبات)
  widgets/      مكونات معاد استخدامها: SealBadge, LivePriceTicker, LedgerCard, EscrowTimeline
  screens/      كل شاشة في فولدر حسب الفلو (auth, home, shop, cart, checkout, orders, price)
```

## الفلو الكامل المربوط

تسجيل الدخول (هاتف → OTP) → الشاشة الرئيسية (تبويبات: استكشف / طلباتي / الدعم / حسابي)
→ تفاصيل المحل → قائمة المنتجات → تفاصيل المنتج → السلة (مع عداد تثبيت السعر)
→ الدفع (شرح الضمان بخطوات) → تأكيد الدفع (رمز استلام) → طلباتي → تفاصيل الطلب
→ تأكيد الاستلام (Checklist قبل تحويل المبلغ للمحل) → تقييم المحل، أو الإبلاغ عن مشكلة.

شاشات إضافية اتضافت مش موجودة في التصميم الأصلي: توثيق الهوية (KYC)، شاشة
تفاصيل الأسعار مع رسم بياني ومنبّه سعر، فلاتر البحث (Bottom Sheet)، شاشة
الإبلاغ عن مشكلة، وشاشة تقييم المحل بعد الاستلام.

## الخطوة الجاية

البيانات كلها دلوقتي جوه `AppStore` (lib/data/mock_data.dart) كـ Mock. لما
تيجي تربطها بـ API حقيقي، الموديلات والواجهات (الشاشات) مش هتتغيّر كتير —
هتستبدل `AppStore` بطبقة Repository بترجع نفس الموديلات من السيرفر.
